# Restaurant-platform (Restoran Deneyim Platformu)

Kullanıcıların restoran menüsünü inceleyebildiği, yemeklerini kendi tercihlerine göre kişiselleştirebildiği, Gel-Al siparişi oluşturabildiği ve sipariş durumunu takip edebildiği web tabanlı bir restoran deneyim platformudur.

## Temel Fonksiyonlar
1. **Menü Görüntüleme:** Menüdeki ürünlerin, açıklamaların, görsellerin ve fiyatların listelenmesi.
2. **Yemek Özelleştirme:** Ürünlere ek malzeme ekleme/çıkarma ve dinamik fiyat hesaplama.
3. **Sepet ve Gel-Al Sipariş Oluşturma:** Ürünleri sepete ekleme, miktar güncelleme ve benzersiz sipariş numarası ile sipariş oluşturma.
4. **Sipariş Takibi:** Sipariş numarası aracılığıyla siparişin güncel durumunun (Alındı, Hazırlanıyor, Hazır, Teslim Edildi) sorgulanması.

## Kullanılan Teknolojiler
- **Backend:** Python, Flask
- **Frontend:** HTML, CSS, JavaScript
- **Veritabanı:** SQLite
- **DevOps & Cloud:** Git, GitHub, GitHub Actions, Docker, Cloud Platform
